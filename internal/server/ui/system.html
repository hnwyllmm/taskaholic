备份位置与最近恢复点

自动恢复点逐库校验并保存；不代表两个数据库在同一时刻提交。不包含原生 Agent Session、工作目录、代码仓库或认证文件。数据库恢复不等于完整运行环境恢复。

当前未确认异机副本。同一台机器、同一块磁盘上的备份不能抵御整机丢失或硬盘损坏。备份未额外加密，应放在受保护的磁盘或目录。

下载只包含控制端记录；自动恢复点的校验清单和 Runtime 队列在上述备份目录内。安全恢复命令仅写入新目录，核对待执行动作前不会启动任务。

当前执行边界

交付方式文本文件 · 版本化保存
工作完成人工验收后关闭
系统进化隔离构建 · 两次确认 · 自动回滚
进程维护升级守护进程 · 自动重启

普通任务不会自动修改仓库或提交 PR。只有在首页聊天明确提出系统升级、确认准备候选版本，并再次确认安装后，升级守护进程才会切换本应用；新版本健康检查失败时回滚。Multica 工单尚未接入。
