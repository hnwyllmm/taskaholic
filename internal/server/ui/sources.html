任务源配置

只导入所选迭代内、精确指派给此人的未完成工单。修改迭代不删除旧任务，也不重复创建已导入工单。身份变化请创建新源。

新版本邀请哪些评审角色

每个角色自动选一名成员，排除原作者；评审完成后汇总回原任务。新 head 会暂停未完成的旧版本评审。不会因为评论作者与 PR 作者同账号就忽略人工意见；系统自动回复必须携带专用标记以防循环。

登记 PR

请选择已开始执行的任务，确保后续反馈回到原成员的 Session。首次登记不补发旧评论，但会检查当前 CI 并评审当前版本。Agent 也能通过交付 JSON 中的 pull_requests 字段自动登记。
